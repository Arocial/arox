# Chat Profile Examples

This directory contains example profiles for the chat app. Customize an
example for your own use, then place it under your user configuration directory
at:

```text
~/.config/arox/profiles/chat/<profile>/config.toml
```

For example, a profile named `coder` should be stored at
`~/.config/arox/profiles/chat/coder/config.toml`. Keep any included files and
their relative paths intact when copying an example.
